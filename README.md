# УниКей (UniKey)

**Бесплатная программа для обработки ключевых слов и текстовых строк.**

УниКей — десктопное Windows-приложение, которое позволяет быстро фильтровать, сортировать, очищать и разбивать списки ключевых слов и любых текстовых данных. Подходит для SEO-специалистов, копирайтеров, маркетологов и всех, кто работает с большими массивами строк.

**Сайт программы:** [vladimir-awm.ru/unikej-besplatnaya-programma-dlya-obrabotki-klyuchevyx-slov](https://vladimir-awm.ru/unikej-besplatnaya-programma-dlya-obrabotki-klyuchevyx-slov/)

## Возможности

### Выборка по включениям и исключениям

Фильтрация входящих строк по двум спискам:

- **Обязательные включения** — в результат попадают только строки, содержащие хотя бы одно значение из списка.
- **Обязательные исключения** — из результата убираются строки, содержащие любое значение из списка.

Для каждого списка доступна галочка **«Полное включение/исключение строки»**:

| Галочка | Поведение | Пример |
|---|---|---|
| Выключена | Частичное вхождение (поиск подстроки) | `127.0.0.11` совпадет с `127.0.0.111` |
| Включена | Полное совпадение строки | `127.0.0.11` **не** совпадет с `127.0.0.111` |

### Сортировка

- **Сортировка А-Я** — алфавитный порядок с учетом текущей локали (корректно сортирует кириллицу).
- **Сортировка Я-А** — обратный алфавитный порядок.

### Перемешивание

- **Перемешать** — случайное перемешивание строк (алгоритм Фишера-Йетса).

### Удаление дубликатов

- **Удалить дубли** — удаление повторяющихся строк с сохранением порядка первого вхождения.

### Разбивка на файлы

- **Разбить на файлы** — делит входящие данные на несколько текстовых файлов по указанному количеству строк в каждом.
- Файлы сохраняются в папку `split/` рядом с exe.
- Формат имен файлов: `2025-01-15_14-30-00_1.txt`, `2025-01-15_14-30-00_2.txt` и т.д.

### Фильтрация по длине строки

- **Символов в строке не более X** — оставляет строки длиной не более X символов.
- **Символов в строке более X** — оставляет строки длиной более X символов.

### Фильтрация по количеству слов

- **Слов в строке не более X** — оставляет строки, содержащие не более X слов.
- **Слов в строке более X** — оставляет строки, содержащие более X слов.

Слова считаются по пробелам (множественные пробелы подряд не создают «пустых» слов).

## Интерфейс

Окно программы разделено на три основные области:

| Область | Описание |
|---|---|
| **Входящие данные** | Исходный список строк для обработки |
| **Обязательные включения / исключения** | Списки слов или фраз для фильтрации выборкой |
| **Результат** | Итоговый список после обработки |

Счетчики непустых строк обновляются в реальном времени для каждого текстового поля.

## Системные требования

- Windows 7 / 8 / 10 / 11
- .NET Framework 4.7.2 или выше

## Быстрый старт

1. Скачайте последний релиз из раздела [Releases](../../releases).
2. Запустите `UniKey.exe` — установка не требуется.
3. Вставьте список строк в поле «Входящие данные».
4. Используйте нужную функцию — результат появится в поле «Результат».

## Сборка из исходников

Требуется Visual Studio 2017 или новее с установленным компонентом «.NET desktop development».

```
git clone https://github.com/<ваш-username>/UniKey.git
cd UniKey
```

Откройте `UniKey.sln` в Visual Studio и соберите проект (`Ctrl+Shift+B`).

Скомпилированный exe появится в `UniKey/bin/Debug/` или `UniKey/bin/Release/`.

## Структура проекта

```
UniKey/
  UniKey.sln                    — файл решения Visual Studio
  UniKey/
    UniKey.csproj               — файл проекта (.NET Framework 4.7.2)
    Program.cs                  — точка входа
    MainForm.cs                 — логика всех функций обработки
    MainForm.Designer.cs        — разметка формы (элементы интерфейса)
    Properties/
      AssemblyInfo.cs           — метаданные сборки
```
